# Ashutosh Kumar Sharma — Personal Developer Portfolio

Modern, high-performance developer portfolio website built using the registered **ThreeUI Sublevel Studio** component foundation, Next.js 14, React 18, TypeScript, and Three.js 0.160.

![Sublevel Studio Portfolio Aesthetics](public/landing-pages/sublevel-studio.html)

## ⚡ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **UI & 3D Core**: Three.js 0.160 + ThreeUI
- **Language**: TypeScript
- **Styling**: Vanilla CSS & ThreeUI Shader Frame

## 🚀 Sections

- **00 / Hero**: Display typography and interactive spatial room scene.
- **01 / About**: Academic and technical background in Computer Science & AI/ML.
- **02 / System Capabilities**: Programming, AI/ML, Web Engineering, and Cloud Tools matrix.
- **03 / Selected Projects**:
  - **CampusPilot AI**: AI-powered study assistant (Next.js, React, AWS, DynamoDB, Lambda).
  - **Hand Gesture Recognition**: Real-time CV recognition system (Python, OpenCV).
  - **Haven Coffee Shop**: Responsive modern web application.
  - **AI Study Assistant**: Experimental learning & productivity platform.
- **04 / Build Log**: 2026 milestones, Club Coordinator leadership, and development initiatives.
- **05 / Education**: B.Tech CSE (AI/ML) at Khalsa College of Engineering and Technology (IKGPTU).
- **06 / Open Source**: Open source callout linking to GitHub repositories.
- **07 / Establish Connection**: Terminal contact interface with client-side validation.

## 🛠️ Local Development

1. Clone repository:
   ```bash
   git clone https://github.com/ak3121091-ctrl/Portfolio.git
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
